# fluttermotion_json

Describe a FlutterMotion composition in JSON and build it at runtime.

`fluttermotion_kit` is a vocabulary of scenes; this package makes that
vocabulary serialisable. A document is data, so it can be written by a
designer, sent by a server, generated by a model, or edited by a tool that
never compiles anything -- and it renders through exactly the same widgets and
the same deterministic frame function as a composition written in Dart.

```dart
final MotionDocument document = MotionDocument.parse(jsonString);
final Composition composition = document.toComposition(data: report);
```

See the JSON section of the [repository README](../../README.md) for the
document shape, the node vocabulary, the binding language and what the layer
was verified against.
