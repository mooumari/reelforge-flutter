# A composition described in JSON

The kit is a vocabulary of scenes; this package is that vocabulary made
serialisable. A document is data, so it can be written by a designer, sent by a
server, generated by a model, or edited by a tool that never compiles anything
-- and it renders through exactly the same widgets and the same deterministic
frame function as a composition written in Dart.

`reel.json`:

```json
{
  "version": 1,
  "id": "Reel",
  "width": 1080,
  "height": 1920,
  "fps": 30,
  "scenes": [
    {
      "seconds": 4,
      "child": {
        "type": "titleCard",
        "kicker": "{{ period }}",
        "headline": "{{ headline }}"
      }
    },
    {
      "seconds": 6,
      "child": {
        "type": "barChart",
        "bars": {
          "over": "weeks",
          "as": {"value": "{{ shipped }}", "label": "{{ label }}"}
        }
      }
    }
  ]
}
```

`report.json`:

```json
{
  "period": "Q3 2026",
  "headline": "Shipped more, broke less",
  "weeks": [
    {"label": "W27", "shipped": 12},
    {"label": "W28", "shipped": 18}
  ]
}
```

The document is the template and the data fills it. `{{ weeks }}` above is a
repeat: the `as` template is built once per item, and inside it the item's own
fields resolve with no prefix, falling back to the root data when they do not
match.

## Building it

```dart
import 'dart:convert';
import 'dart:io';

import 'package:reelforge/reelforge.dart';
import 'package:reelforge_json/reelforge_json.dart';

final MotionDocument document =
    MotionDocument.parse(File('reel.json').readAsStringSync());

final Composition composition = document.toComposition(
  data: jsonDecode(File('report.json').readAsStringSync())
      as Map<String, Object?>,
);
```

Or skip the Dart entirely -- the CLI renders a document directly, writing the
host entry point for you:

```bash
reelforge render reel.json --data report.json --out reel.mp4
```

## Checking it first

A document and its data are valid separately and can still render nothing
together, which is how you get sixty seconds of empty scenes and an exit code
of zero. `reelforge validate` answers both questions, and needs no build:

```bash
reelforge validate reel.json --data report.json
```

The format itself -- the node vocabulary, the binding language, every check --
lives in `reelforge_schema`, which has no Flutter dependency. It is re-exported
here, so a renderer needs only this one import.
